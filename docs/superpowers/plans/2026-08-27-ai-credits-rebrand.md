- [ ] **Step 3: Replace every `@platform/` import**

On Windows PowerShell (no sed), run a recursive replacement over the scoped file set (use the `pwsh` tool):

```powershell
$targets = Get-ChildItem -Recurse -File -Include *.ts,*.tsx,*.json,*.md -Path packages, apps, scripts, tests 2>$null | Where-Object { $_.FullName -notmatch 'node_modules|dist|\.vercel' }
$targets += Get-Item docs\DEPLOYMENT.md
foreach ($f in $targets) {
  $c = Get-Content $f.FullName -Raw
  if ($c -match '@platform/') {
    $c = $c -replace '@platform/', '@ai-credits/'
    Set-Content -Path $f.FullName -Value $c -NoNewline -Encoding UTF8
  }
}
```

Verify the replacement scope with a grep: after the run, `@platform/` must appear ONLY under `docs/superpowers/*` (list matches to confirm), and `@ai-credits/` must appear in the 69 expected files.
